# nonnet 1.0.0

## Initial CRAN release

* Added functions for generating and detecting nonlinear relations in networks.
* Added `netgen()` for generating nonlinear networks.
* Added `dcor_res()` for detecting nonlinear relations using a residualization procedure based on distance correlations.
* Methods are based on Slipetz, Qiu, Sun, and Henry (2026), [doi:10.48550/arXiv.2411.02763](doi:10.48550/arXiv.2411.02763).
